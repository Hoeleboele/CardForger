PROJECT: CARDFORGE STUDIO

OVERVIEW

Build a fully browser-based Trading Card Creation and Management application called CardForge Studio.

The application must run entirely on the client side with no required backend. All user data should be stored locally using IndexedDB and LocalStorage.

CardForge Studio allows users to:

- Create card templates
- Design cards using layered elements
- Generate cards from templates
- Manage card sets
- Manage decks
- Duplicate cards in bulk
- Export individual cards
- Export print-ready sheets
- Work fully offline

The application should feel like a combination of Photoshop, Figma, and a Trading Card Game deck editor.
